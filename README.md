# 九溪（JiuXi）

> 综合信息聚集地 —— **AI 为主，热点新闻为辅，其它为次辅**。
> 本地优先的静态信息站：无需服务器、无需后端，内容由仓库内文件 + 浏览器端实时抓取共同驱动。

- 当前版本：**Phase 0 · 工程初始化（玻璃外壳骨架）**
- 技术栈：**Astro 5** + **Tailwind CSS 4**（纯静态输出）
- 托管目标：**Cloudflare Pages（主站）** + **GitHub Pages（备用副站）**

---

## 一、本地运行（看效果）

需要本机有 Node.js 22+（你新年买电脑后装即可；当前由技术伙伴在沙箱构建）。

```bash
npm install      # 安装依赖（首次）
npm run dev      # 本地开发预览，终端会给出 http://localhost:4321
npm run build    # 生成静态站点到 dist/（部署用）
npm run preview  # 本地预览构建产物
```

> 手机没电脑期间，想随时看效果：让技术伙伴起本地预览，或在部署上线后用手机浏览器直接访问公网地址。

## 二、项目结构（当前）

```
jiuxi/
├─ src/
│  ├─ layouts/BaseLayout.astro   # 液态玻璃外壳（渐变背景 + 居中玻璃卡）
│  ├─ pages/index.astro          # 首页（当前为占位骨架）
│  └─ styles/
│     ├─ global.css              # Tailwind v4 入口
│     └─ glass.css               # 玻璃令牌 + .glass 毛玻璃材质
├─ astro.config.mjs              # Astro 配置（接入 Tailwind，静态输出）
├─ package.json                  # 依赖与脚本
└─ README.md                     # 本文件
```

后续阶段会逐步补齐：`components/`（玻璃组件）、`content/`（时间线/工具箱/读书策展数据）、`themes.css`（多套主题）、`functions/`（Cloudflare 代理）等。

## 三、如何编辑内容（手机也能做）

九溪有两类内容：

1. **策展内容**（AI 发展时间线 / AI 工具箱 / 读书推荐）：改仓库里的数据文件，推送后自动上线。手机浏览器登录 GitHub → 打开文件 → 点铅笔图标编辑 → 提交即可。
2. **动态资讯**（AI / 新闻 / 科技 / 游戏）：由站点在浏览器端实时抓取公开源，无需你维护。

> 具体数据格式与模板会在 Phase 4 提供。

---

## 四、部署（推送到 GitHub 后自动上线）

已确认采用**双站部署**：

- **主站 · Cloudflare Pages**：无限带宽、全球 CDN、可做实时聚合代理。仓库连 Cloudflare 后 push 即部署。
- **备用副站 · GitHub Pages**：同一份静态产物直接部署，作为容灾镜像。

部署由技术伙伴借助开源部署技能完成配置，你只需 `git push`，无需敲命令。

`astro.config.mjs` 里的 `site` 字段在绑定正式域名后更新即可。
