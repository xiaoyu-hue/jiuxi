由 Peter Steinberger 发起（原 ClawdBot → Moltbot，2026 年 1 月定名 OpenClaw），MIT 协议，数月内冲到 GitHub 30 万+ Star，成为「史上 Star 最多的软件仓库」之一。它跑在用户自己的 macOS / Windows / Linux 甚至 NAS 上，通过 WhatsApp、Telegram、Discord、企业微信、QQ、钉钉等 20+ 聊天软件接收自然语言指令，操作文件、执行终端命令、写脚本、管邮件日历；模型（Claude / GPT / Gemini / DeepSeek / 本地模型）与技能插件均可插拔，技能市场 ClawHub 已有 3000+ 插件，社区俗称「AI 龙虾」。

项目由独立的 OpenClaw Foundation（501(c)(3)）托管，无订阅、无托管服务、无代币——「本地优先 + 模型无关」的路线与云端 SaaS 助手形成鲜明对照，是 2026 年个人 Agent 开源生态的代表作。
