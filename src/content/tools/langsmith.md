LangSmith 是 LangChain 生态的官方运维平台： tracing 定位每次 Agent 运行的每一步（含 LangGraph 节点级追踪），Dataset + Evaluator 做回归评测，Playground 迭代提示词，Hub 托管提示词版本。对用 LangGraph 构建复杂 Agent 的团队，它提供开箱即用的调试与质检能力。

云服务为主、核心 tracing 亦提供自托管选项；与开源替代 Langfuse 形成「生态绑定 vs 部署自由」的经典取舍。
