2025 年 3 月发布，取代实验性项目 Swarm 成为 OpenAI 官方 Agent 开发框架：以 Agent / Handoff / Guardrail / Session 四个原语覆盖多智能体委派、工具调用、输入输出校验与会话状态，内置追踪面板，Python 与 TypeScript 双 SDK。

它的定位是「够用的最小框架」——不追求大而全，而是把官方最佳实践（Responses API、内置工具、计算机使用）固化成 API，是 LangGraph / CrewAI 之外最省心的官方路线。
