Agent Development Kit（ADK）是 Google 2025 年 4 月开源的 Agent 框架，与 Gemini 模型、Vertex AI 深度绑定：用工作流 Agent（顺序 / 并行 / 循环）与 LLM 驱动 Agent 组合出复杂系统，内置工具、记忆、评测与本地开发 UI，一行命令部署到 Cloud Run 或 Agent Engine。

对押注 Google 生态（Gemini + Vertex）的团队，ADK 是官方通道；与 OpenAI Agents SDK 的「轻量原语」路线相比，它更偏向「生产部署全家桶」。
