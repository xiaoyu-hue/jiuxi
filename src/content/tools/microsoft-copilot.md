Microsoft Copilot 是微软把 OpenAI 模型铺进全产品线的统一入口：消费端有 copilot.microsoft.com 与 Windows 任务栏助手，企业端有 Microsoft 365 Copilot（Word / Excel / PPT / Outlook / Teams 内嵌）。2026 年 3 月的 Wave 3 更新标志其「多模型策略」摊牌——Copilot Cowork 直接把 Anthropic 的 Claude Cowork 技术请进 Office，官方口号「你的工作不被某一个模型品牌限制」。

依托 Windows 与 Office 的分发优势，Copilot 是企业市场触达最广的 AI 助手；与 GitHub Copilot（编程）分工明确。
