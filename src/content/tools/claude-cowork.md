2026 年 1 月 12 日随 Claude Desktop（macOS）研究预览上线，官方定位「用于其他工作的 Claude Code」：在隔离虚拟机中本地运行，可读写指定文件夹、整理桌面、把收据截图转成表格、由笔记生成文档草稿，支持浏览器自动化与 MCP 连接器；4 月 9 日在 macOS 与 Windows 正式推出（GA），并加入分析 API 与 OpenTelemetry 监控。

Cowork 开创了「桌面 Agent」品类，发布后阿里 QoderWork、MiniMax 桌面 Agent、阶跃 AI 桌面伙伴等国内厂商一月内悉数跟进，开源侧则有 OpenClaw 对标。它与终端编码 Agent（Claude Code）构成 Anthropic 的「双端」布局。
