Roo Code 是 Cline 的社区分支，也是 2025 年 GitHub 上增长最快的开源编码 Agent 之一：在 VS Code 里直接读写文件、执行命令、操作浏览器，把「提需求 → 自主完成多文件改动」变成日常。相比原版，它提供更细的角色模式（架构师 / 编码 / 调试可分别配模型）、更强的 MCP 支持与自定义能力。

对想「自托管编码 Agent、不被单一厂商绑定」的团队，Roo Code 与 Continue、Cline、Aider 共同构成开源编程 Agent 的主力阵营。
