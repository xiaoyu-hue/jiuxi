2025 年 6 月 19 日发布、7 月 WAIC 首秀的通用 Agent 产品，口号「代码很便宜，把需求拿给我」：多智能体系统多步规划，端到端交付深度研究、PPT、全栈网页与浏览器操作等长程任务，内置 MCP 生态（Google Maps、GitHub、Figma 等）与长期记忆。10 月接入专为 Agent 优化的 M2 模型并推移动端；2026 年 1 月上线桌面 App 与 Web 2.0「专家 Agent」，4 月新增 Pocket（接入飞书、微信）。

与 Manus、Genspark 同属「中国系通用 Agent」第一梯队，差异化在于模型—Agent 垂直整合（跑在自研 MiniMax 模型上）与按 token 计价的透明商业模式。
