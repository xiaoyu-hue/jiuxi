PydanticAI 把 FastAPI 的「开发者体验」带进 Agent 开发：用 Pydantic 模型定义工具与输出（类型安全、IDE 补全、校验一步到位），支持依赖注入、流式响应、持久化与全链路可观测，底层模型无关（OpenAI / Anthropic / Gemini / 本地均可）。

在 LangChain 偏「重」、裸调 API 偏「轻」之间，它成为 2025 年 Python 技术团队构建生产 Agent 的热门选择——尤其适合已经习惯 FastAPI 工程范式的后端团队。
