---

MCP 由 Anthropic 于 2024 年 11 月开源，解决「每个 AI 应用都要为每个工具重写一遍集成」的痛点：用统一协议把工具、数据库、文件系统暴露成 AI 可调用的 server。一年内 SDK 月下载量破 9700 万、活跃 server 超 1 万个，ChatGPT、Claude、Cursor、Gemini、Microsoft Copilot、VS Code 全部原生支持。

2025 年 12 月 9 日，Anthropic 将 MCP 捐赠给新成立的 Agentic AI Foundation（Linux 基金会旗下，Anthropic / Block / OpenAI 联合创立，Google、微软、AWS 等为白金成员）——与 Kubernetes 当年如出一辙的「中立化」一步，标志 MCP 成为智能体时代的事实标准。对自建 Agent 的团队，MCP 是连接层的默认答案。
