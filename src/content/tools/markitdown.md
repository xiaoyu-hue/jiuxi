MarkItDown 是微软开源的「万物转 Markdown」工具：把 Office 三件套、PDF、图片（走多模态模型描述）、音频（Whisper 转写）、网页与 ZIP 统一转成 Markdown，保留标题、表格、列表结构，供 LLM 消化。Python 库 + CLI + MCP server 三种用法，两行代码进任何 RAG 管道。

与 MinerU（PDF 学术解析）、Marker（PDF）、Docling（IBM）同属「文档解析」赛道，MarkItDown 胜在格式覆盖广、与微软生态衔接顺、还能当 MCP 工具直接喂给 Agent。
