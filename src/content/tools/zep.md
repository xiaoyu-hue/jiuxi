Zep 解决 Agent「记不住事」的痛点：把对话历史抽取成带时间戳的事实，存入时序知识图谱（开源核心 Graphiti），支持增量更新、失效推断与混合检索，让 Agent 跨会话记住用户偏好、实体关系与历史决策。

对客服、个人助理、销售 Copilot 等需要「越用越懂你」的场景，Zep 与 Mem0、Letta 同属 Agent 记忆层三强，差异在 Zep 以图谱为中心、强调事实的时序一致性。
