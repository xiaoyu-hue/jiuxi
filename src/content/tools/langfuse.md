Langfuse 是 LLM 应用的「可观测性 + 评测」基础设施：记录每次模型调用的完整 trace（ prompt、工具、耗时、成本），做 A/B 评测与线上质量监控，管理提示词版本与标注数据集。开源可自托管（Docker 一条命令），也提供云服务。

Agent 应用最怕「跑得起来但说不清为什么这么跑」——Langfuse 与 LangSmith 是填补这个空白的两大主力，前者开源友好，后者与 LangChain 绑定更深。
