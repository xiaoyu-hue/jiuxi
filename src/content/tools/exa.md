Exa（前 Metaphor）不做「给人看的十条蓝链接」，而是把查询转成向量、检索全网网页后返回结构化的干净内容（标题、正文、摘要、发布日期），专为 LLM 的上下文窗口设计。开发者可用 embeddings 搜索、关键词搜索与「找相似网页」三类 API 为 RAG 管道与深度研究 Agent 供血。

在 Tavily、Brave Search API 等同类中，Exa 的检索质量与结果组织最受 Agent 框架作者青睐，是 2025 年以来 AI 应用最常用的搜索 API 之一。
