2026 年 1 月 12 日（北京时间 13 日），Anthropic 在 Claude Desktop（macOS）推出 **Claude Cowork** 研究预览，官方定位是「用于其他工作的 Claude Code」：在隔离虚拟机中本地运行，直接读写指定文件夹内的文件，能一键整理桌面、把收据截图转成表格、把笔记生成文档草稿，支持浏览器自动化与 MCP 连接器，不确定时主动向用户提问。

Cowork 把 Agent 从「开发者终端」带进「普通打工人桌面」，发布后迅速引爆桌面 Agent 赛道：阿里（QoderWork）、MiniMax、阶跃星辰等国内厂商一月内悉数入场，开源项目 OpenClaw（原 Clawdbot/Moltbot）同步走红；2 月初甚至引发 SaaS 软件股的恐慌性抛售。4 月 9 日 Cowork 在 macOS 与 Windows 正式推出（GA），并加入分析 API、OpenTelemetry 监控与基于角色的访问控制。

> 交叉引用：前身 Claude Code 见 2025-02；微软 3 月将其引入 Microsoft 365（见 2026-03）；云端托管智能体见 2026-04 Managed Agents。
