title: OpenAI Agents SDK 与 Manus：通用 Agent 浪潮
category: 智能体

2025 年 3 月，OpenAI 发布 Agents SDK 与 Responses API，把「agent」确立为官方一等公民的产品概念（取代此前的「assistant」话术）。同月，中国 Monica 团队发布通用自主 Agent **Manus**，能端到端规划并执行复杂多步任务（做 PPT、筛简历、写报告）。

至此「Agent 框架」成为各前沿实验室标配：OpenAI Agents SDK、Anthropic Claude Agent SDK（9 月）、Google ADK 相继登场，Agent 从概念走向工程标准。资本同步狂热——2025 年 Q1 Agent 创业公司融资约 87 亿美元，同比 +143%。
