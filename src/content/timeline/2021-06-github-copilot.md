title: GitHub 与 OpenAI 发布 Copilot，「AI 副驾」走进千万编辑器
category: 智能体
---

2021 年 6 月 29 日，GitHub 发布 **GitHub Copilot** 技术预览：基于 OpenAI Codex 模型，在 VS Code 里根据注释与上下文实时补全整段代码，把「AI 结对编程」第一次带到普通开发者的日常工具栏。

Copilot 开创了「AI 编程助手」这一品类，两年内用户破百万，并倒逼整个行业跟进（Cursor、Windsurf、通义灵码、文心快码……）。它的演进本身就是一部微缩 AI 史：从单行补全 → Copilot Chat 对话 → 2023 年接入 GPT-4 的 Copilot X → 2025 年支持自主编码的 Agent 模式，编码由此成为大模型最早规模变现的场景。

> 交叉引用：Copilot 的底座是 2021 年 8 月发布的 OpenAI Codex（见 2021-08），而「真正干活的编码 Agent」由 2025 年 2 月的 Claude Code 与 2024 年 3 月的 Devin 推向新阶段。
