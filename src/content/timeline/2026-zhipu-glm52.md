2026 年 6 月 17 日，智谱开源发布旗舰模型 **GLM-5.2**，主攻「长程任务」与 **1M** 上下文，在全球百万用户参与的 Code Arena 盲测中位列可用模型第一；以最宽松 MIT 协议开放权重，并 Day 0 适配华为昇腾、寒武纪、摩尔线程等国产算力。标志国产开源模型从「可用」迈向「好用」，与 Anthropic、OpenAI 旗舰形成直接竞争。

> 交叉引用：GLM-5.2 的「长程任务」是 Agent 主线的延伸（见 Claude Code 2025、DeepSeek V4 Agent 能力 2026）；其「开源 + 国产算力」组合呼应自主可控叙事（见 DeepSeek V4 2026）。
