category: 智能体

2025 年 2 月，Anthropic 发布 Claude Code——一个跑在终端里的编码 Agent，能读仓库、改文件、跑命令、提 PR。Claude 3.5/3.7 Sonnet 成为当时编码 Agent 工作负载的首选模型。

Claude Code 把「Agent 当同事用」变成开发日常，深刻影响了 Cursor、Windsurf、Codex、与各厂内部编码 Agent 的形态，是「Agentic 编程」普及的标志性产品。
