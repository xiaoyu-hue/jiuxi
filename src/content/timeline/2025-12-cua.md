title: OpenAI 发布 CUA，Computer-Using Agent 标准化
category: 智能体
---

2025 年 12 月，OpenAI 发布 CUA（Computer-Using Agent）模型能力，把「看懂屏幕并操作 GUI」做成可复用的基础能力，承接此前 Claude Computer Use 的探索。

与 Anthropic 的 Computer Use、Google 的 Mariner 一道，CUA 把「视觉+操作」的 Agent 范式标准化，使 Agent 能直接驱动未提供 API 的传统软件，进一步拓宽自主 Agent 的可用面。
