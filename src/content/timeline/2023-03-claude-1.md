2023 年 3 月 14 日，由 OpenAI 前高管达里奥·阿莫迪（Dario Amodei）等人创立的 Anthropic 正式发布 **Claude**（及轻量版 Claude Instant）——与 GPT-4 发布同日亮相，率先将「宪法式 AI」（Constitutional AI，见 2022-12）的无害化训练方法产品化。

Claude 1 以超长上下文（初期约 10 万 token，后扩至 20 万）、克制的对话风格与「不讨好用户」的安全感著称，第一时间通过 Poe 与 Slack 等渠道开放体验。此后两年 Claude 家族一路迭代（Claude 2 → 3 → 3.5 → 4 → 4.7），在编程与 Agent 场景形成与 OpenAI、Google 三足鼎立的格局。

> 交叉引用：Claude 2 见 2023-07；Claude Code 编码 Agent 见 2025-02；Opus 4.7 见 2026-04。
